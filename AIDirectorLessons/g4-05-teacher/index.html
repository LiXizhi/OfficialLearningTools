准备与演示

投屏材料与操作

  • A 卡：纸，干净；B 卡：塑料，干净；C 卡：纸，有污点；D 卡：布，干净。这些都是课堂图卡。
  • 本关只收干净的纸和塑料。其他卡停在入口，退给操作员。
  • 路线甲先问“是纸或塑料吗”，再问“干净吗”；路线乙交换两问。遇到否马上退回，两问都是才按材质进纸道或塑料道。

local tests = {
    {q="甲路线放入 B，最后去哪？", options={"纸道", "塑料道", "退回"}, correct=2, evidence="B 是干净塑料，两门都是，进塑料道。"},
    {q="仅把两道门换序，C 的判断步数怎样变？", options={"两步变一步", "一步变两步", "仍是两步"}, correct=1, evidence="甲先通过材质门才被污点退回；乙在清洁门直接退回。"},
    {q="D 在两种路线的终点怎样？", options={"都进纸道", "甲退回乙进塑料道", "都退回"}, correct=3, evidence="布不在接收范围，换序只影响什么时候发现它。"}

setActorValue("sentientRadius", 0)
registerClickEvent(function()
    local index = ask("想复核哪一次测试？", {"基准", "改变条件", "换个场景"})
    local test = tests[index]
    if not test then return end
    local answer = ask(test.q, test.options)
    if not answer then return end
    if answer == test.correct then
        say("判断成立。" .. test.evidence, 6)
        turnTo(90)
    else
        say("停下核对材料。" .. test.evidence, 6)
        turnTo(0)
    end
end)

🧭 五步教学法 · 40 分钟课堂流程（教师大屏主导）

  1. 【第1步｜情境导入 · 0—5 分钟】真实问题切入：大屏展示一张缺少“否则”分支的流程图，请学生指出当遇到不符合条件的物品时，机器会卡在哪里。
  2. 【第2步｜概念理解 · 5—13 分钟】原理拆解与预测：结合本课主题（第4章 规则与算法（流程图）），请学生先写出或说出自己的判断与理由，同桌互查依据。
  3. 【第3步｜工具体验 · 13—25 分钟】白名单工具实操：在 Paracraft 的创作入口新建一个空白世界。根据上一课总结的回收物分类特征，画出“先看材质→再看是否干净→送入对应回收区”的条件判断流程图，并在 Paracraft 中搭建对应的双通道分拣站。 核对基础达标证据：单一材质的干净物品能严格按照流程图步骤进入正确的分拣区域。
  4. 【第4步｜项目实践 · 25—35 分钟】控制变量与对比实验：只改变一个条件——调换两个判断条件的先后顺序，观察分拣路径和步数是否发生变化，核对最终分类结果是否一致。 请学生对比前后变化并记录过程证据。
  5. 【第5步｜伦理反思 · 35—40 分钟】安全边界与过程评价：围绕“在教师提供的模拟数据集与3D场景中开展标注和规则实验，使用公开或虚拟物品数据。”开展反思；离堂思考：如果换一个真实校园场景，你会先核查哪项数据或边界条件？
💡 课堂常见卡点与排障锦囊

先确保起点、关键路标与终点能在同一视角看清；先用最简单的1个正常样本跑通流程，再逐步加入分支条件或例外物品。
