🎯 本课教什么（核心教学目标与评价证据）

核心任务：编写带标签的“时间查询”与“地点查询”训练问句各3条，另留2条测试问句；用单文件 HTML 词频分类小程序统计两类词表得分，体验模型训练、预测与重训全过程。

基础达标证据：分类器能根据训练样本词频为新问句打出“时间类得分”与“地点类得分”，并在平分时自动输出“待人工确认”。

控制变量/进阶探究：针对一条因使用同义词（如“在哪儿/什么位置”）而分流失败的测试题，向训练集补充1条含该同义词的样本并重新训练，验证模型指标提升。

学段安全与伦理边界：在明确任务与记录要求下分析生成内容的逻辑、事实与偏差；智能体须配置拒答边界与转人工机制。

  3. 【第3步｜核对第一轮证据】检查是否达到预期结果：分类器能根据训练样本词频为新问句打出“时间类得分”与“地点类得分”，并在平分时自动输出“待人工确认”。

🧪 微型词频分类器编写指南（双路线）

手写探究路线：在空白 HTML 中录入“时间查询、地点查询”两组带标签问句，按词切分并统计两类词频权重；输入测试问句累计得分，平分时显示“待人工确认”。

AI协作路线：在 AIChat 中提供自己编写的 6 条训练样本，要求生成单文件 HTML 词频分类器，展示每个词的权重得分，再用预留的 2 道闭卷测试题验证，体会训练与重训过程。
