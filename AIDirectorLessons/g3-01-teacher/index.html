🗳️ 全班大屏互动投票：这 4 件校园设备，谁装了“AI 大脑”？

“同学们，早上进校门时，如果有一台 3D 虚拟具身迎宾机器人看着你的校牌向你挥手问好；走进教室，班长按了一下墙上的电灯开关灯亮了。大家先别急着下结论——请先独立思考 10 秒钟：下面的 4 件设备里，哪些真的用到了人工智能（AI）？哪些只是普通固定电路机器？现在我们全班举手投票！”

🤖 1. 校门刷脸迎宾具身机器人

看画面认校牌 + 挥手迎宾

✅ 有 AI（图像识别+具身控制）：摄像头采集图像 → 模型提取特征匹配 → 驱动手臂与闸机行动。

🌿 2. 植物角平板拍照识花App

拍树叶照片 → 显示植物名称

✅ 有 AI（图像分类识别）：识别叶片形状、叶脉与锯齿特征并计算匹配概率。

🏠 3. 温馨客厅智能语音音箱

听语音提问 → 播报今日天气

✅ 有 AI（语音识别+自然语言处理）：将声波转为文字、理解意图并合成语音回答。

💡 4. 教室墙面普通翘板电灯开关

手指按下 → 电路接通灯亮

⚙️ 无 AI（普通机械开关）：仅靠铜片物理接触通断电流，不会感知图像或声音，也不会分析判断。

-- Paracraft 代码方块 (CodeBlock) · 校门虚拟具身迎宾机器人 (g3-01)
-- 装配方式：拉杆 -> 代码方块 (219) <-> 电影方块 (含迎宾机器人演员)
-- 遵循 c:/lxzsrc/keepworkExtension/skills/paracraft-create/references/code-blocks.md 规范
setActorValue("sentientRadius", 0)
setActorValue("name", "gate_embodied_robot")

local mode = "normal" -- normal(正常清晰) | occluded(遮挡逆光) | noisy(环境嘈杂)

local function actByEnv(envMode)
    if envMode == "normal" then
        say("☀️【感知清晰 98%】认出本校同学校牌！同学早安，欢迎进入智慧校园！", 4)
        turnTo(0)
        walkForward(1, 0.8)
        wait(0.3)
        walkForward(-1, 0.8)
    elseif envMode == "occluded" then
        say("🕶️【视觉受阻 42%】镜头被遮挡看不清特征！我已停步亮黄灯，请摘下遮挡或请值班老师人工核验！", 5)
        turnTo(45)
    elseif envMode == "noisy" then
        say("📢【语音受扰】周围太吵把“下雪”听成“下学”啦！请走近麦克风重说一遍，或请老师帮忙确认！", 5)
        turnTo(-45)
    end
end

-- 启动时先执行一次正常迎宾
actByEnv(mode)

-- 点击具身机器人可切换控制变量实验条件
registerClickEvent(function()
    local idx = ask("🤖 我是校门虚拟具身迎宾机器人！请选择要测试的环境条件（控制变量实验）：", {
        "☀️ 1. 环境正常（画面清晰 + 声音清楚）",
        "🕶️ 2. 视觉干扰（雨伞/逆光遮挡摄像头一半）",
        "📢 3. 语音干扰（周围大声喧哗 + 同音字）"
    })
    if idx == 1 then
        mode = "normal"
    elseif idx == 2 then
        mode = "occluded"
    elseif idx == 3 then
        mode = "noisy"
    else
        return
    end
    actByEnv(mode)
end)

第 5 步 · 随堂检测与伦理反思（35—40 分钟）
