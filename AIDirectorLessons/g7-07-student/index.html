拐早一格的导览日志

给伙伴一张路线日志。让他不用看你的操作，用坐标和三行记录找到机器人拐早的原因，并让它停在服务台前。

桌上的材料

  • 俯视格图：向东为x加1，向南为y加1。起点（0,0）朝东；唯一转角（3,0）向南；服务台前停点（3,2）。南侧通道只有x=3可通。
  • 模拟语音卡“去服务台”解析为目标服务台；看到右箭头时右转，然后直行；看见终点牌时停止。
  • V1记录：在（2,0）看到右箭头；规划右转；角色从朝东转成朝南，下一步被墙挡住。
  • 正确复测记录应在（3,0）看到箭头，转向南后经过（3,1）至（3,2）。迁移日志：箭头位置正确，规划右转，实际仍朝东。

使用约定　路标和语音都用预设输入模拟，不录音、不采集同学图像。日志按亲眼看到的坐标填写。

先比较两个方案，再把选择理由记下来。

从材料区挑一条能支持你作品的依据，用“引用到本步记录”保存它，并写下你为什么选它。

做出首版后请同伴试一次。先记他做了什么，再问他原本想做什么。

同伴先猜出错层，再原样运行V1，写下首次偏差。只移箭头后用同一语音卡、同一起点重跑V2，须在（3,2）停止。

在 Paracraft 搭一个本课复核站

先开空白世界，把建景委托带入主对话。建好后打开拉杆，点向导选两种条件，核对它的台词和朝向。

行为脚本
local tests = {
    {q="V1在哪一格首次出现与正确路线不同的输入？", options={"（3,2）看到终点", "（2,0）看到右箭头", "（3,1）进入南向通道"}, correct=2, evidence="V1过早在（2,0）读到右箭头；右转决策与实际朝向都相符。"},
    {q="仅把箭头移回（3,0），角色接下来经过哪里？", options={"（3,1）后到（3,2）", "（4,0）后到（5,0）", "（2,1）后到（2,2）"}, correct=1, evidence="角色从朝东右转成朝南；题设向南使y增加，x保持3。"},
    {q="新日志说“（3,0）读到右箭头，决策右转，角色继续朝东”。先查哪里？", options={"语音卡的目的地", "箭头提前了一格", "把决策变成转向动作的执行步骤"}, correct=3, evidence="感知位置与路标正确，规划也给出右转，但实际朝向仍为东，差异首次发生在执行。"}
}
setActorValue("sentientRadius", 0)
registerClickEvent(function()
    local index = ask("想复核哪一次测试？", {"基准", "改变条件", "换个场景"})
    local test = tests[index]
    if not test then return end
    local answer = ask(test.q, test.options)
    if not answer then return end
    if answer == test.correct then
        say("判断成立。" .. test.evidence, 6)
        turnTo(90)
    else
        say("停下核对材料。" .. test.evidence, 6)
        turnTo(0)
    end
end)

🎯 本课教什么（核心教学目标与评价证据）

核心任务：在 Paracraft 校园导览场景中设置转角路标与终点服务台，模拟导览机器人在“视觉认路标 + 语音听指令 + 路径规划执行”多模态协同下的工作过程。

基础达标证据：当某个转弯路标被故意提前放早一格时，能通过逐步观察定位出是“感知位置偏差”还是“转向执行规则错误”，并修复到位。

控制变量/进阶探究：只将偏移的路标移回正确路口重新运行，验证角色沿预期路线精准停在服务台前。

学段安全与伦理边界：使用可视化实验与低代码工具理解数据驱动模型原理，关注样本偏差对不同人群的公平性影响。

🛠️ 五步上机实践指南（学生独立闯关 · 约 25—40 分钟）

  1. 【第1步｜明确问题与环境准备】在 Paracraft 的创作入口新建一个空白世界。 回顾课堂导入问题：播放导览机器人撞墙或走错门的视频片段，请全班像AI工程师一样按“感知→决策→执行”三步排查故障根源。
  2. 【第2步｜说出意图与基础实操】使用上方【和 AI 聊】或进入 Paracraft：在 Paracraft 校园导览场景中设置转角路标与终点服务台，模拟导览机器人在“视觉认路标 + 语音听指令 + 路径规划执行”多模态协同下的工作过程。
  3. 【第3步｜核对第一轮证据】检查是否达到预期结果：当某个转弯路标被故意提前放早一格时，能通过逐步观察定位出是“感知位置偏差”还是“转向执行规则错误”，并修复到位。
  4. 【第4步｜控制变量对比实验】只改变一个条件再运行一次：只将偏移的路标移回正确路口重新运行，验证角色沿预期路线精准停在服务台前。
  5. 【第5步｜伦理自查与成果提交】对照安全规范（不录入个人隐私、如实标注AI辅助过程），整理两次实验对比记录并存入个人第二大脑。
