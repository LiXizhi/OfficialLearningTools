# Bumi 具身智能通识课 · H5 版

把 [bumi-edu-docs-v2](../bumi-edu-docs-v2/Bumi具身智能通识课程总览与使用说明.md) 的 16 课做成两个网页，直接用浏览器打开即可，不需要服务器：

| 页面 | 给谁 | 内容 |
| --- | --- | --- |
| [student.html](student.html) | 学生 | 课程目录和 16 课学习单。横线、方框可以直接填写和勾选，画图格可以用鼠标或手指画，也可以打印后手写 |
| [teacher.html](teacher.html) | 教师 | 课程总览、课程介绍、课程大纲，16 课教案；每课另有“学生学习单”分栏，“课后记录”可直接填写 |

两个页面都要和 `assets/` 文件夹、`world-launcher.js`、`embedded-preview.js` 放在一起。拷贝或部署时请带齐这些文件；`_tools/` 只在重新生成时需要。

学生页面不含参考回答，也不链接到教师页面。

## 使用提示

- 独立打开课程时，“打开小布米世界”仍在新窗口打开。在 AIChat 等嵌入式预览中，`world-launcher.js` 会在课程内显示世界，点“返回课程”可继续填写。首次点击才加载世界；返回课程会关闭仿真，但保留课程填写和位置。若预览环境限制了仿真运行，可用“复制世界网址”到浏览器打开；无法自动复制时，选中网址按 Ctrl+C 即可。此适配不修改 AIChat 框架。
- 在 AIChat 中，`embedded-preview.js` 会隐藏学生版和教师版的全部打印按钮，并让教师页的“学生页面”在课程内打开。点“返回教师页面”后，教师页原来的位置和填写保留；再次打开也会保留当前学生页的填写和位置，直到刷新或关闭教师页。独立打开课程时，打印按钮和学生页的新窗口入口保持原样。
- 填写内容只保存在当前电脑的当前浏览器里（localStorage），不上传；换电脑、换浏览器或清理浏览数据后不会保留。多人共用一台电脑时，课前用每课底部的“清空本课填写”。
- “打印本课”只打印当前这一课；教师页面打印的是当前分栏。
- 每幅图右上角的“放大”可以单独投影这幅图；教案里提到配图的链接也会直接弹出对应的图。
- 网页地址后面的 `#l01` … `#l16` 是各课的直达位置，教师页面的 `#l01-s` 是该课的学生学习单分栏。

## 配图

- **机器人**：`assets/robot/` 里的图由 `_tools/render_robot.py` 用仓库中的真实 Bumi 模型离线渲染，配色取 `parax/bumi.colors.json` 的“原厂银灰”整机方案（配色对比图另用蓝白、黑金、红白三个方案）。站姿是运行合同的默认关节角；行走帧是现成行走模型在物理仿真中的采样（`_tools/walk-poses.json`）；舞蹈、跳跃、倒地帧直接取自已有回放数据。它们都不是网页运行截图，也不代表新功能。
- **教学图解**：按 v2 各图的内容在 `_tools/figures.py` 里重新绘制，标签、按钮名和数值与 v2 一致。图里的虚线是给打印后手写用的，网页填写在正文的输入框里。
- **沿用 v2 的两幅图**：小组观察插画（AI 辅助生成，人物与场景为虚构）和此前的 Web 测试截图，压缩后放在 `assets/img/`。

与 v2 文字不同的地方只有两处，都是因为配图换了：课程介绍开头的小布米形象图注改为说明“真实模型离线渲染”；课程总览“八、配图与来源”开头加了一段 H5 版配图说明。

## 重新生成

课程文字以 v2 的 Markdown 为准。v2 改动后，从资产仓库根运行：

```
python bumi-edu-docs-v2-h5/_tools/build.py
```

重新生成页面后，请保留两个 HTML 的 `</body>` 前的 `<script src="world-launcher.js"></script>` 和 `<script src="embedded-preview.js"></script>`，以保留嵌入式预览的适配。

只用 Python 标准库，会重写两个页面并自检（未转换的 Markdown 记号、缺失的图片、重复的图编号）。需要增加或修改图解时改 `_tools/figures.py`；v2 新增的图片路径要在其中的 `FIGURES` 里登记，否则生成会报错。

机器人图片一般不需要重渲。要换姿态、角度或配色时：

```
python bumi-edu-docs-v2-h5/_tools/render_robot.py
```

需要 `mujoco` 和 `numpy`；系统里有 `ffmpeg` 时输出 WebP，否则保留 PNG（此时 `assets/robot/index.json` 会记录实际文件名，再运行一次 `build.py` 即可）。
