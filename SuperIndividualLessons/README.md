# 超级个体培训课（四节课）

打开 [index.html](index.html) 即可离线学习。课程分四节，沿“理念 → 建脑 → 上手 → 组织”一条成长线展开，全程约 85 分钟，可分次学完；课时进度自动保存在本浏览器。适合用任意 AI 对话工具和普通文件夹跟做。

## 四节课

| 课 | 标题 | 时长 | 学什么 | 文件 |
| --- | --- | --- | --- | --- |
| 1 | 超级个体 | 约 15 分钟 | 碳基 + 硅基的融合、一人多分身、成长四阶段（口喷 → 燃烧 Token → 建脑 RSI → AI 原生产品），每阶段配 AI 生成插图。 | `idea.js` / `idea.css` |
| 2 | 第二大脑 | 约 15 分钟 | 三层结构（原始信源 / 知识地图 / 维护规则与 Skills）、四模块工作循环（工作台 / 大脑 / 工具 / 圈子，经验回流）、RSI。 | `idea.js` / `idea.css` |
| 3 | 上手工作 | 约 40 分钟 | 模拟真实 AIChat 工作台演示 + 角色放映室 + 任务卡：读脑、并行、判断、写回，亲手训练自己的分身。 | `sim.js` / `day.js` / `practice.js` |
| 4 | 超级组织 | 约 15 分钟 | 超级个体 → 超级团队 → 超级公司、岗位组织 vs 圈子组织、分身信任网络、CAIO 新岗位（四件事交付）、FDE 三步验收。 | `org.js` |

课时路由、课程目录卡与进度记忆在 `lessons.js` / `lessons.css`；开场英雄区在 `hero.css`。兼容旧锚点：`#idea`→第1课、`#sim`/`#day`/`#practice`→第3课、`#lesson-N` 直达。放映室 `#screen`/`#timeline` 在默认第1课打开时点击会自动切到第3课（保持既有 e2e 契约）。

理念与演示的内容依据李西峙第二大脑：`_wiki/concepts/second-brain.md`、`_wiki/concepts/ai-native-company.md`、`notes/Xizhi's Diary/2026.10.28 碳基与硅基的融合`、`docs/2026/super-individual-stages.md`、`docs/2026/xiaoetong-trust-sharing`。演示界面配色取自 AIChat `css/base.css` 的浅色令牌；场景数据为教学模拟，与放映室共用 `roles.js`。第4课的组织形态与商业判断标注为理念推演，CAIO 定价为口述口径，非已交付承诺。

## 程序驱动的短片

每个角色有六镜：现场、委托、对证、建脑、复跑、交接。连续播放约一分钟，对证镜头停下来让学员查看两份记录再作判断。分镜可独立查看，支持暂停、重播和系统中文语音旁白（设备提供语音时）。教学案例与材料为模拟数据，界面参考图保留原图查看入口。

八张角色场景图由 ImageGen 生成。每个角色使用相同人物的开场与交接画面；镜头推移、对白、逐字输入、文件更新和版本比较由浏览器本地驱动。

第1课成长四阶段另配四张 ImageGen 插图（`assets/stage-1-voice.webp` … `stage-4-product.webp`，1024px WebP，深绿 + 酸橙 + 靛蓝 + 米色纸感，无文字），随阶段切换。原始 PNG 在 `assets/gen/`，发布时只需 WebP。

## 课程与图像来源

- 李西峙第二大脑《成为超级个体》笔记（2026-11-09，`docs/2026/super-individual-stages.md`）。四阶段依次为口述委托、并行调度、通过 RSI 建脑并组织分身、交付 AI 原生产品并验证盈利。

- 《WorkBuddy 与我们的第二大脑》（`docs/2026/baoan-caio-workbuddy.html`）。FDE 按项目交付，CAIO 持续协助组织采用和维护。
