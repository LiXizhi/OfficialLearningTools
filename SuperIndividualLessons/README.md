# 超级个体培训课（四节课）

直接用浏览器打开 [index.html](index.html) 即可离线学习（或通过 AIChat 课堂库打开）。课程按“**先看现场 → 搭第二大脑 → 工作台实操与任务卡 → 组织演进与六问诊断**”四节递进，全程约 85 分钟，支持按顶部统一**身份视角**（学生 / 老师 / 领导 / 创业者）贯穿全课，课时进度与任务卡自动保存于浏览器（并在嵌入课堂库时同步宿主缓存）。

## 四课结构与学习产出

1. **第 1 课 · 超级个体：理念与现场一天（约 20 分钟）**
   - `1.1 先看现场`：通过六幕工作日常对比“模糊提问”与“清晰委托 + 双分身核查 + 人工裁决”。
   - `1.2 核心定义`：理解“碳基 + 硅基 = 一人多分身”，个人第二大脑对自己透明可控、对外部圈子显式授权。
   - `1.3 成长路径`：3 个能力阶段（口喷时代 → 燃烧 Token → 建脑 RSI 与一人多分身）+ 1 个商业检验（AI Native 产品盈利）。
   - `1.4 本课自检`：1 分钟即时选择题。
2. **第 2 课 · 第二大脑与建脑循环（约 20 分钟）**
   - `2.1 目录拆解`：4 个标签页预览真实 `Git + Markdown` 目录（`raw/` → `_wiki/index.md & log.md` → `_wiki/projects/*.md` 含双源矛盾保留 → `AGENTS.md & .github/skills/`），附 `10 → 50–100 → ~200` 篇规模约束与“一份资料 ≠ 一个词条”规则。
   - `2.2 方式对比`：裸聊 AI vs 纯向量 RAG vs LLM Wiki 第二大脑（核查机制与幻觉边界说明）。
   - `2.3 运营闭环`：Ingest / Query / Lint / RSI 日常四动作 + 建脑四模块交互循环图。
   - `2.4 两条建脑路径`：个人学习者（场景公共脑 → 个人脑）与企业组织（组织脑 → 成员个人脑 `fork brain / brain-sync`）。
3. **第 3 课 · AIChat 工作台回放与四步任务卡（约 25 分钟）**
   - `3.1 模拟 KeepWork AIChat`：7 步同步回放同一角色的真实工作流，支持工作流内交互判断，并一键将方案带入任务卡。
   - `3.2 四步任务卡工坊`：围绕“① 清晰委托 → ② 双分身压测 → ③ 建脑与 RSI → ④ 盲测与试点”，保留 10 字段自动保存、纯文本复制、`.txt` 导出与第二大脑 `.md` 启动包下载。
4. **第 4 课 · 超级组织、信任网络与 CAIO / FDE 落地（约 20 分钟）**
   - `4.1–4.3`：超级个体 → 超级团队 → 超级公司演进、传统岗位 vs 圈子组织、4 项 AI 原生运作原则（`.agents/` & `/协作`、`朋友圈 ≠ 工作台`、`3–10 CLI + Skills`、`Stress Test Agent`）、跨组织信任网络与 `keepwork-crm`、WorkBuddy 桌面助手 vs KeepWork 组织脑，以及 CAIO 按月陪伴构想与 FDE 三步工程交付法。
   - `4.4`：**首次诊断六问**一页试点卡交互生成器，支持复制到剪贴板或一键同步回第 3 课任务卡。
   - `4.5`：全课认识论边界声明（明确区分已实现功能、试点方法与远期推演/假设）。
