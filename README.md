# OfficialLearningTools

帕拉卡官方课程源码。下载仓库，打开下列目录内的 `index.html` 即可浏览课程。

- [超级学生 AI 通识课](AIDirectorLessons/README.md) 面向三至九年级，56 课均提供教师与学生入口。
- [超级个体培训课](SuperIndividualLessons/index.html) 一课时，选学生、老师、校长 / 主任 / 领导或 IPO 创业者，观看一天的工作，建立自己的任务、第二大脑和分身。[课程与素材来源](SuperIndividualLessons/README.md)
- [和小布米一起理解具身智能](BumiLessons/README.md) 包含 8 个单元、16 课时的教师教案、学生学习单及互动实验。

欢迎通过 Issue 提交课堂反馈，或通过 Pull Request 贡献修改。原创代码使用 MIT 许可证。引用的上游教材、图片、数据和外链资源保留各自的权利与使用条件，来源见各课程说明。
